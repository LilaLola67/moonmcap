**项目名称与方向**：MoonMCAP——MoonBit 原生 MCAP 日志读写、索引与变换基础库；方向为通用基础库 / 二进制数据基础设施。

**GitHub 仓库**：https://github.com/LilaLola67/moonmcap（公开，已有不少于 10 条实质开发提交，分别实现格式、校验、读写、索引、查询、变换及恢复等能力）。

**项目简介及通用性**：以 MoonBit 为主要实现语言，独立实现 MCAP 时间戳消息容器的核心能力。为机器人、传感器采集、仿真回放与离线日志工具提供可复用 API；消息负载保持原始字节，不绑定 ROS、特定消息编码或图形界面。采用 moonc 0.10.14 及以上版本。

**预期使用场景**：①机器人运行后，读取 MCAP，按主题与故障时段筛选消息、统计时序异常，导出含相关声明及附件的复现日志；②多设备采集后，合并同配置日志，去重声明、重映射冲突 ID、对齐时间，再交给分析或回放工具；③采集程序中断后，定位截断处，恢复连续可解析记录与完整块，重新生成有效文件并报告恢复边界。

**核心功能与进度**：已实现有界二进制编解码、顺序及无压缩分块读写、数据/摘要/块/附件 CRC32、消息与块索引、附件与元数据索引、主题/时间查询及分页、裁剪/合并/时间平移、分片解码、状态化录制、时序统计和前缀恢复。当前手写核心有效源码 2,537 行（排除测试、示例、注释、空行和生成代码），42 项测试通过，具备可运行示例与官方 Python MCAP 双向互操作检查。已配置检查、构建、测试 CI；初审后完善压缩适配、磁盘按需查询、性能及覆盖验证，并发布 mooncakes.io。

**原创、参考及查重**：本项目是独立编写的 MoonBit 实现，非现有源码移植；参考 [MCAP 规范](https://mcap.dev/spec) 与 [foxglove/mcap](https://github.com/foxglove/mcap)（MIT），本项目采用 MIT。2026-10-10 检索 GitHub 和 mooncakes.io，未发现检索范围内其他 MoonBit MCAP 同类核心库；相邻 BagDrop 为 ROS2 SQLite 浏览器分析应用，与本项目格式及交付物不同。详见仓库查重记录，不宣称格式首创或全网绝无重复。
